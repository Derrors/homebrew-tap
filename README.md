# Derrors/homebrew-tap

Homebrew formulas for [iphone-control](https://github.com/Derrors/iphone-control): let AI agents operate a real iPhone or iPad over USB.

```bash
brew install derrors/tap/iphone-control
brew services start iphone-control   # run the daemon now and at login
iphone-control setup                 # connect the iPhone with a cable first
iphone-control mcp-config            # prints the command that registers the MCP tools
```

macOS on Apple Silicon, and Linux (x86_64, arm64; the daemon also needs the system's `usbmuxd`).

`Formula/iphone-control.rb` is generated by the iphone-control release workflow (`packaging/homebrew/formula.sh`); changes belong there.
